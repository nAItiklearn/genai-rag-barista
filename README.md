# ☕ Coffee Barista RAG Agent

An AI-powered coffee shop assistant built with Google ADK, Gemini, Streamlit, and Google Cloud.

## Features

- 🤖 AI Barista powered by Gemini
- 📚 RAG-style menu retrieval using a local JSON knowledge base
- 🔎 Recommends drinks and pastries based on user preferences
- ⚠️ Provides allergen information
- 💬 Maintains conversation context
- ☁️ Deployed on Google Cloud Run

## Tech Stack

- Python
- Google ADK
- Gemini
- Streamlit
- Google Cloud Vertex AI
- Google Cloud Run
